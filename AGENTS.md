## 🎯 Alcance del Proyecto y Módulos Clave

Al generar código o proponer soluciones, mantén presente la arquitectura funcional de los siguientes módulos:

1. **E-Commerce & Portal Público (Astro + React):**
   - Menú digital responsivo y catálogo de productos.
   - Carrito de compras, pedidos para llevar/domicilio y sección de **pedidos de mayoreo**.
   - Encuestas de satisfacción dinámicas post-compra.

2. **Portal de Empleados & Sistema POS (React / Islas):**
   - Interfaz ágil para punto de venta (optimizado para tablets/pantallas táctiles).
   - Módulo de capacitación interna para el personal.
   - Panel de control de comandas e inventario en tiempo real.

3. **Fidelización y Monedero Electrónico:**
   - Sistema de acumulación de puntos y monedero digital por cliente.
   - Validación y lectura rápida mediante **código QR**.

4. **Motor de Promociones y Reglas de Negocio:**
   - Creación y cálculo dinámico de descuentos, cupones y reglas acumulables.

---

## 🛠️ Stack Técnico Oficial

- **Frontend:** Astro 6.4.6 + React 19 (Islas de interactividad)
- **Styling:** Tailwind CSS 4.3 + shadcn/ui
- **Fuentes:** Geist (vía `@fontsource-variable/geist`)
- **Gestor de Paquetes:** `pnpm`
- **Base de Datos & ORM:** PostgreSQL + Prisma ORM (en la nube)
- **Infraestructura & Deploy:** Vercel (Analytics + Speed Insights)
- **Entorno:** Node.js >=22.12.0
